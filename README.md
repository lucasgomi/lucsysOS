# LucsysOS

LucsysOS es una edición personalizada de Windows 11 con **LucsysOS Panel**, una aplicación para gestionar el equipo: energía, rendimiento, virtualización, controladores, sincronización, fondos de pantalla, cuentas y más.

## Actualizaciones

Las actualizaciones del panel se publican en [Releases](../../releases). Cada versión incluye un paquete `.lucsysupd`.

- LucsysOS Panel las busca desde **Configuración › Acerca de › Actualizaciones de LucsysOS** y el agente avisa una vez al día cuando hay una versión nueva.
- Cada paquete está **firmado**: el panel comprueba la firma y el contenido de cada archivo antes de instalar nada, y rechaza paquetes modificados o versiones anteriores a la instalada.
- Las versiones marcadas con **[seguridad]** corrigen problemas del panel o de sus scripts y conviene instalarlas cuanto antes.

Las imágenes de instalación (ISO) se publican aparte cuando hay cambios importantes.
